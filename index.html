Vacation Planner

Organize vacations and excursions, search by vacation title or lodging, generate summary reports, share vacation details, and schedule notifications.

Version: 1.0 | Requires: Android 8.0 or later

Download Android APK

Installation

  1. Open this page on an Android device and download the APK.
  2. Open the downloaded file. If Android requests permission, allow installation from this browser or file manager only if you trust this download.
  3. Select Install, then open Vacation Planner. The installed app may appear as “D308 Vacation Planner” because this capstone extends the original D308 application.
  4. Allow notifications if you want vacation and excursion alerts. You can turn off the installation permission afterward.

Getting started

Open the vacation list and add a vacation. Save it before adding excursions or setting alerts. Excursion dates must fall within the vacation’s dates, and the vacation’s end date must be after its start date.

Successful edits cancel that record’s existing alerts. Reopen the saved record to set any desired alerts again. Remove associated excursions before deleting a vacation.

Your data

No account is required. Vacation and excursion records are stored locally on your device and are not synchronized between devices. Uninstalling the app or clearing its storage removes those records.
